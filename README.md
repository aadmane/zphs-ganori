### 🚀 GitHub वर होस्ट कसे करावे? (How to Host on GitHub Pages)

ही वेबसाईट पूर्णपणे **Static Web (HTML5, CSS3, JavaScript)** असल्याने कोणत्याही सर्व्हर किंवा डेटाबेस शिवाय **GitHub Pages** वर मोफत व आजीवन चालते.

#### पद्धत १: GitHub Desktop किंवा Web द्वारे (सर्वात सोपी पद्धत):
1. **GitHub.com** वर लॉगिन करा आणि **New Repository** तयार करा (उदा. `zphs-ganori` किंवा `ganori-school`).
2. या फोल्डरमधील (`website zphs`) सर्व फाइल्स (`index.html`, `css/`, `js/`, `images/`, `README.md`, `.nojekyll`) त्या रिपॉझिटरीमध्ये **Upload** करा किंवा Git Push करा.
3. रिपॉझिटरीच्या **Settings** ➔ **Pages** (डाव्या मेनूमध्ये) वर जा.
4. **Build and deployment** अंतर्गत:
   - **Source:** `Deploy from a branch`
   - **Branch:** `main` (किंवा `master`), फोल्डर `/ (root)` निवडा.
   - **Save** बटनावर क्लिक करा.
5. अवघ्या १ मिनिटात तुमची वेबसाईट लाइव्ह होईल:
   `https://<your-username>.github.io/<repository-name>/`
